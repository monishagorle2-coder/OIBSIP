# Tempora. – Temperature Converter

Tempora. is a simple, interactive, and responsive temperature converter built using HTML, CSS, and Vanilla JavaScript. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin with instant results.

## Features

- **Multiple Unit Conversion:** Convert between Celsius, Fahrenheit, and Kelvin.
- **Live Conversion:** Automatically updates the result when the temperature or selected units change.
- **Quick Temperature References:** Use preset values for common temperatures:
  - Freezing point of water – 0°C
  - Room temperature – 25°C
  - Human body temperature – 37°C
  - Boiling point of water – 100°C
- **Swap Units:** Quickly switch the source and target temperature units.
- **Input Validation:** Displays an error for empty or invalid input.
- **Absolute Zero Validation:** Prevents temperatures below absolute zero.
- **Reset Option:** Clear the input and restore the default settings.
- **Responsive Design:** Works on desktop and mobile screens.

## Technologies Used

- HTML5 – Page structure
- CSS3 – Styling and responsive layout
- JavaScript (Vanilla JS) – Conversion logic and interactivity

## How to Run

1. Download or clone this repository.
2. Open the `WebDev-L1-TemperatureConverter` folder.
3. Open `index.html` in your browser.
4. Enter a temperature and select the units to convert.

You can also open the project in Visual Studio Code and run it using the Live Server extension.
