# Travilo – Explore the City of Destiny

## About the Project

Travilo is a simple travel website that I created to help people explore interesting places in and around Visakhapatnam.

I chose Vizag as the main focus because it has many beautiful places, from beaches and hills to historical sites and peaceful locations. I also wanted to include some nearby areas so visitors could discover more places beyond the city.

The main idea behind Travilo is to make it easier for someone to explore different destinations without having to search for each place separately.


## Features (What can you do with Travilo.)

- Explore tourist destinations across six regions.
- View multiple attractions by selecting a region.
- Attraction cards with images and descriptions.
- Responsive layout for desktop and mobile screens.
- Simple navigation between Home, Explore Places, and About sections.

## Regions Covered

The website currently covers these areas:
1. Vizag City
2. Bheemili
3. Anakapalli & Surroundings
4. Madugula & Paderu
5. Araku Valley
6. Devarapalli & Nearby Getaways

## Technologies Used

- HTML5 – Website structure ( To create the structure of the website.)
- CSS3 – Styling and responsive layout
- JavaScript – Dynamic region selection and attraction display

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in a browser.
4. Select a region from the dropdown to explore its attractions.
