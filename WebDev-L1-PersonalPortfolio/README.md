# Personal Portfolio – Gorle Monisha

## About
A personal portfolio website showcasing my background,
technical interests, academic projects, education and contact details.

## Features
- Personal introduction and profile
- About Me section
- Technical skills
- Academic and personal projects
- Education and certifications
- Contact links to Email, GitHub and LinkedIn
- Responsive layout for different screen sizes

## Technologies Used
- HTML5
- CSS3

## Project Structure
WebDev-L1-PersonalPortfolio/
├── index.html

## How to Run
1. Download or clone the OIBSIP repository.
2. Open the WebDev-L1-PersonalPortfolio folder.
3. Open index.html in a browser.
4. Alternatively, use the VS Code Live Server extension.
